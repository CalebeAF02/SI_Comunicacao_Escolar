\begin{objectives}
Descrever o modelo conceitual a partir de \textbf{todos os requisitos funcionais} e da
atividade de organização dos dados da Entrega 2. Nesta etapa, não é necessário desenhar o DER.
\end{objectives}

\begin{notebox}[Antes de preencher]
Retomem o BPMN (AS-IS), a matriz de rastreabilidade, as histórias e os cenários BDD,
bem como as tabelas da última atividade assíncrona. Não comecem do zero: usem esses materiais
para decidir o que o sistema precisa registrar.
\end{notebox}

\begin{keyidea}[Ligação entre as atividades]
BPMN $\rightarrow$ necessidades $\rightarrow$ requisitos RF $\rightarrow$ dados identificados
$\rightarrow$ MER (hoje) $\rightarrow$ DER (próxima aula).
\end{keyidea}
